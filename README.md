# 📇 Contacts Management System

A web-based contacts management application built with **PHP**, **MySQL**, and **XAMPP**.  
Designed to manage user roles, contacts, registration, authentication, and administration tasks.

---

## 🚀 Features

✅ Secure user authentication (Login, Logout, Registration)  
✅ Role-based access control (Admin & Normal Users)  
✅ Add, Edit, Delete & View Contacts  
✅ Admin dashboard to manage system settings  
✅ Security improvements:
- Password hashing
- Environment variables for DB connection
- `.gitignore` for sensitive files

---
